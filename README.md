# Backend Architect Portfolio

Welcome to my personal portfolio. I am a Backend Architect focused on building high-performance digital products, specialized in Python, Microservices, and Scalable AWS Infrastructure.

## Overview

This portfolio showcases my professional journey, technical skills, and selected projects. It features a modern, agency-style UI with interactive elements and a high-performance backend-focused presentation.

## Tech Stack

- **Languages:** Python 3.12+ (AsyncIO), Java 21
- **Frameworks:** FastAPI, Pydantic V2, Spring Boot 3.2
- **Infrastructure:** AWS (Lambda, S3, RDS), Docker, Kubernetes, Terraform (IaC)
- **Databases:** PostgreSQL (TimescaleDB), Redis (Pub/Sub & Cache)
- **Messaging:** Apache Kafka
- **AI:** LangChain (AI Agents)

## Key Features

- **Interactive Canvas Animation:** A custom-built grid animation that responds to mouse movement.
- **Smooth Scroll Controller:** A bespoke navigation system for a seamless single-page experience.
- **Bento Grid Layout:** Modern design pattern to showcase experience and results efficiently.
- **Responsive Design:** Optimized for various screen sizes, from mobile to ultra-wide displays.

## Project Structure

- `index.html`: The main entry point and structure of the site.
- `script.js`: Custom JavaScript for animations and navigation logic.
- `style.css`: Custom CSS for the visual identity and layout.
